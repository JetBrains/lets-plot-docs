Tooltip Customization

You can customize the content, values formatting and appearance of tooltip for any geometry layer by using the parameter tooltips. The parameter takes as value the result of the layerToltips() function call.

Learn more (datalore link).

See also the formatting reference to learn how to format numeric and date-time values in tooltips.
