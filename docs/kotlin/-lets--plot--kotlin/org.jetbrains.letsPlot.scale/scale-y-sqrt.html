Continuous position scales (y) where trans='sqrt'

Parameters

name

The name of the scale - used as the axis label or the legend title. If None, the default, the name of the scale is taken from the first mapping used for that aesthetic.

breaks

A numeric vector of positions (of ticks).

labels

A vector of labels (on ticks).

limits

A pair of numbers specifying the data range for the scale. Use null to refer to default min/max. Set limits if you want values to be consistent across multiple plots. Setting limits will remove data outside of the limits.

expand
    A numeric vector of length two giving multiplicative and additive expansion constants.
    The vector size == 1 => only multiplicative expand (and additive expand by default).
    Defaults: multiplicative = 0.05, additive = 0.
