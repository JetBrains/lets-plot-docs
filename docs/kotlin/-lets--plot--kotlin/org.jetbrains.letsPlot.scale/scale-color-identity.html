scaleColorIdentity

fun scaleColorIdentity(name: String? = null, breaks: List<Any>? = null, labels: List<String>? = null, limits: List<Any>? = null, naValue: Any? = null, format: String? = null, guide: Any? = null): Scale

Use this scale when your data has already been scaled. I.e. it already represents aesthetic values that ggplot2 can handle directly. This will not produce a legend unless you also supply the breaks and labels.

Input data expected: list of strings containing a) names of colors (i.e. 'green') b) hex codes of colors (i.e 'x00ff00') c) css colors (i.e 'rgb(0,255,0)')

Format patterns in the format parameter can be just a number format (like "d") or a string template where number format is surrounded by curly braces: "{d} cylinders". Note: the "$" must be escaped as "\$" For more info see: https://github.com/JetBrains/lets-plot-kotlin/blob/master/docs/formats.md
