What is new in 3.0.0¶

Added¶

  • geom_imshow():

    • Improved performance by orders of magnitude.

    • Transparency of NaN values in grayscale images [#631]. See: example notebook.

    • alpha parameter [#630]. See: example notebook.

  • geom_violin():

    • tails_cutoff parameter. See: example notebook.

  • New ‘bistro’ plot - residual_plot().

    See: example notebook.

  • New geometry geom_area_ridges().

    See: example notebook.

  • New geometry geom_pie().

    See: example notebook.

  • Annotations for pie chart:

    See: example notebook.

  • New variables computed by 'count' and 'count2d' statistics: '..sum..', '..prop..', '..proppct..'.

    See: example notebook.

  • Static maps:

    • The value "provided" for use_crs parameter.

      See: example notebook.

Changed¶

  • Java/Swing platf.: Apache Batik upgraded to v.1.16 [#624], [LPK #140].

  • The default size is increased for the plot title and decreased for the caption.

Fixed¶

  • Themes: can’t change plot background after applying a "flavor" [#623].

  • Layout: uneven left/right, top/bottom plot margins [#625].

  • A plot building error with empty data on various geoms.

  • Precision error in gradient [#634].

  • geom_livemap: wrong position when datapoints geodesic line goes close to the N.P. [#645].
