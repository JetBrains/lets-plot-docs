Markdown Support#

Markdown can be used in titles only and is disabled by default. To enable it, set element_markdown() for the appropriate element in theme().

Currently supported features:

  • Emphasis (*, **, ***, _, __, ___)

  • Coloring with inline style (<span style='color:red'>text</span>)

  • Links with anchor tags (<a href="https://lets-plot.org">Lets-Plot</a>)

  • Multiple lines using double space and a newline delimiter (  \n)

Not supported features:

  • Tag <br/> for line splitting

  • Links styling

  • Links with Markdown syntax ([Lets-Plot](https://lets-plot.org))

import numpy as np
import pandas as pd

from lets_plot import *

LetsPlot.setup_html()

df = pd.read_csv("https://raw.githubusercontent.com/JetBrains/lets-plot-docs/master/data/mpg.csv")
df.drop(columns=["Unnamed: 0"], inplace=True)
print(df.shape)
