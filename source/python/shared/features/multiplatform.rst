Multiplatform

A :doc:`Grammar of Graphics for Python </python/index>` - works in Python notebooks (|jupyter-quickstart|, |datalore-quickstart|, |kaggle-quickstart|, |colab-quickstart|, |deepnote-quickstart|, |nextjournal-quickstart|) as well as in |ides-quickstart|.

A `Grammar of Graphics for Kotlin <https://lets-plot.org/kotlin/index.html>`__ - a Kotlin multiplatform visualization library which fulfills your needs in the Kotlin ecosystem: from Kotlin notebooks to `Compose-Multiplatform apps <https://github.com/JetBrains/lets-plot-skia>`__.
