.. title:: Requirements


Requirements
============

- Python >= 3.8 (for geocoding)

- `NumPy <https://numpy.org>`__ >= 1.24.2

- `pandas <https://pandas.pydata.org>`__ >= 1.5.3

- `GeoPandas <https://geopandas.org/en/stable/>`__ >= 0.12.2

- `Shapely <https://shapely.readthedocs.io/en/stable/>`__ >= 2.0.0
